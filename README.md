# AdventureWorks Sales Analytics

## 📊 Project Overview

This project analyzes sales data from the AdventureWorks database to identify sales trends, product performance, customer behavior and regional performance.

The goal is to transform raw business data into meaningful insights that can support data-driven decision making.

This project is part of my Data Analytics portfolio and demonstrates an end-to-end workflow using SQL, Python and Power BI.

---

## 🎯 Business Questions

The analysis aims to answer questions such as:

* How have sales evolved over time?
* Which product categories generate the most revenue?
* Which products perform best?
* Which regions generate the most sales?
* How does sales performance vary across territories?
* Which salespeople generate the highest revenue?
* How has performance changed compared with previous years?

## 🔎 Analysis

### Sales Performance

Analysis of sales evolution over time, including yearly revenue, number of orders and average order value.

### Product & Category Analysis

Analysis of product and category performance to identify the main revenue drivers.

### Regional Analysis

Analysis of sales across different territories and regions to identify the strongest markets.

### Salesperson Analysis

Analysis of salesperson performance and revenue contribution.

### Year-over-Year Analysis

Comparison of yearly performance using SQL window functions to identify changes in sales over time.

## 💡 Key Insights

Some initial findings from the analysis include:

* Bikes account for approximately **86% of total sales**.
* North America represents approximately **72% of total sales**.
* Sales peaked in **2013**, reaching approximately **$49.0M**.
* Mountain-200 Black, 38 is currently the highest-revenue product identified in the analysis.

More insights will be added as the analysis progresses.
